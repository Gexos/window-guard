# Window Guard v0.5.0

v0.5.0 focuses on project polish and open-source integration.

## What's new

- New File, Applications, Tools, GitHub, and Help menus
- Direct access to the official GitHub repository from Window Guard
- Open Latest Release and All Releases
- Report Bug / Request Feature through GitHub issue forms
- View existing Issues
- Copy the repository URL
- Open the Window Guard configuration folder
- Open the application folder
- Updated About window showing **Giorgos Xanthopoulos aka gexos**
- Updated HTML/PDF help manual
- GitHub bug-report and feature-request forms
- Pull request template
- GitHub Actions syntax-check workflow

## Security note

Window Guard remains a privacy/convenience lock rather than administrator-proof Windows security. See `SECURITY.md` and the Help manual for details.
