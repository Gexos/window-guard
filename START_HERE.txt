WINDOW GUARD v0.6.0 — START HERE
=================================

This is the v0.6.0 test build. It's not a published release yet.

1. Extract this ZIP to a new folder.
2. Exit the old Window Guard from its tray icon.
3. Run run_window_guard.bat, or build_window_guard.bat for an EXE.
4. Test the icon, Settings window, PIN locking, relock-on-close, tray and Help menu.
5. Follow TESTING_CHECKLIST_v0.6.0.txt.

Your existing PIN and protected-app list are kept here:
%APPDATA%\WindowGuard\config.json

Make a backup of that file before testing if you want to be careful.
Never upload your personal config.json to GitHub.

This package includes the source, icon files, Help manual (HTML/PDF),
GitHub files, build scripts and tests.

After testing, use GITHUB_UPDATE_STEPS_v0.6.0.txt to update your repo.
Don't tag or publish v0.6.0 before checking the Windows build.
