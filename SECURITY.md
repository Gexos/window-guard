# Security Policy

Window Guard is a privacy and convenience utility. It is not intended to provide tamper-resistant security against Windows administrators, users who can terminate processes, debugging tools, another Windows account, or privileged software.

Ending the Window Guard process can defeat its protection model. These are known architectural limitations.

If you discover a security issue that goes beyond the documented limitations, please open a GitHub issue with enough information to reproduce it. Do not include passwords, private keys, personal data, or other sensitive information in a public issue.
