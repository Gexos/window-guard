# Window Guard v0.3.0 — Early Preview

Window Guard v0.3.0 expands the project into a practical multi-application privacy utility for Windows.

## Highlights

- Protect multiple applications with one PIN
- Select the real running executable from a visible-window list
- Lock all protected apps with **Lock Now**
- Keep watching protected applications while locked
- Automatically hide protected windows opened after locking
- System tray support
- Optional Start with Windows
- Failed-PIN cooldown
- Diagnostics for troubleshooting

## Security Note

Window Guard is a privacy and convenience lock. It is not designed to resist a Windows administrator or a user who can terminate the Window Guard process.

For actual workstation security, use normal Windows account protection and `Windows + L`.
