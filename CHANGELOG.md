# Changelog

## 0.6.0 — Released (11-09-2026)

- Added a Window Guard icon for the EXE, windows and tray.
- Added a Settings window.
- Added an optional **Ctrl+Shift+L** Lock All shortcut.
- Added **Export Diagnostics** to save a TXT report.
- Added a **Check for Updates** link to GitHub Releases.
- Updated the Help files and Windows build script.
- Reduced unnecessary app-list refreshes.
- Kept existing PINs and protected apps when migrating older configuration files.
- Fixed a case where windows could be hidden before a PIN was set.
- Added an optional confirmation before removing a protected app.
- Removed deleted apps from the pending PIN prompt queue.

## 0.5.0

- Added File, Applications, Tools, GitHub and Help menus.
- Added the About window and HTML/PDF Help files.
- Added GitHub links and community templates.

## 0.4.0

- Saved protected apps between launches.
- Relocked apps when their running processes closed.

## 0.3.0

- Added support for multiple protected apps, a tray icon and Windows startup.

## 0.2.0

- Added **Select Running App** to pick the process that owns a visible window.
